# tetr.zig
*Tetris clone... in ZIG!*

[Play Here](https://shuflduf.github.io/tetr.zig)

My first proper Zig project, made using [sokol-zig](https://github.com/floooh/sokol-zig) and WASM.

# Features
- Piece movement
- Line clears
- SRS kicks
- DAS and ARR
- Lock delay
- Scoring
  - TSpins
- 7-Bag piece system
- Auto-retry
- UI

# Controls
- A: Move left
- D: Move right
- Left arrow: Counter-clockwise
- Right arrow: Clockwise
- S: Hard drop
- W: Soft drop
- Left shift: Hold piece
